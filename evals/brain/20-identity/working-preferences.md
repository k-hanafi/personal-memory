# Working preferences

Alex uses Codex for grading rubrics. Prefers async comments on drafts
instead of a live walkthrough of the same file.

Default stack is Claude Code for research scripts and Codex for the
rubric pass. Alex does not ask a model to invent a grade.

A draft goes out with a short note on what to look at. Reviewers reply
in the thread. Alex applies the comments in one sitting.

Meetings are for a stuck call, not for first-pass review. If a comment
can be a sentence in the margin, it stays written.
